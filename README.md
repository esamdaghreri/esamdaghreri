### How I think about engineering

- **Business first, code second.** Understanding the domain is the hard part; the code is easy once you do.
- **The simplest correct thing wins.** Three clear lines beat a clever abstraction. Boring and reliable beats impressive.
- **If it isn't written down, it doesn't exist.** Reasoning that lives in one head can't scale or be trusted.
- **Leverage over output.** A leader's job is to multiply the team, not out-code it.
